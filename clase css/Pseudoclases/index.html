Pseudoclases y Pseudoelementos en CSS

:hover (pasar el mouse encima)

Esta caja cambia de color al pasar el mouse

:active (al hacer clic)

:focus (al hacer foco en el input)

:first-child y :last-child

  • Primer item (first-child → azul)
  • Segundo item
  • Tercer item
  • Cuarto item
  • Último item (last-child → rojo)

:nth-child(n)

  • Item 1
  • Item 2 (nth-child(2) → verde)
  • Item 3
  • Item 4 (nth-child(even) → fondo gris, par)
  • Item 5
  • Item 6 (nth-child(even) → fondo gris, par)

:not() (excluir elementos)

  • Item normal (afectado)
  • Item con clase "excluido" (NO afectado)
  • Item normal (afectado)
  • Otro excluido (NO afectado)
