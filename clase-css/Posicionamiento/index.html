Posicionamiento en CSS (position)

position: static (por defecto)

Static: sigo el flujo normal. top/left no me afectan.

position: relative

Relative: me moví 20px abajo y 30px a la derecha de mi posición original.

↑ Nota el espacio vacío arriba: es donde el elemento ESTABA originalmente.

position: absolute

Soy el contenedor (position: relative)

Absolute: estoy posicionado respecto a mi contenedor padre.

position: fixed

Fixed: estoy fijo en la esquina inferior derecha.

El elemento fixed se queda pegado aunque hagas scroll.

position: sticky

Haz scroll dentro de esta caja para ver el efecto sticky:

Sticky: me pego al hacer scroll
